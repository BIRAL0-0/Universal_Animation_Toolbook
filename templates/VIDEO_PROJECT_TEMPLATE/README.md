# Video project skeleton

This directory documents the project skeleton; the actual files are generated by
[`scripts/new_project.py`](../../scripts/new_project.py) into `projects/<slug>/`.

```bash
python3 scripts/new_project.py video-003-topic \
    --title "What Happens If You Stop Using Your Phone?" \
    --format "9:16" --runtime "60 s"
```

The generator refuses to overwrite an existing folder, copies the single master prompt into
`PROMPT.md`, substitutes the supplied title/slug/format/runtime, writes placeholder headers for
every required artifact, creates `assets/`, `audio/` and `renders/`, copies the validated minimal
episode spec (with the empty `channel_name` key removed), and derives `SCENE_PLAN.json` from it.

It does **not** write research, scripts, a finished MP4 or QA results: those are production stages
owned by the skills. The authoritative checklist is
[`PROJECT_FILES.md`](PROJECT_FILES.md); the master prompt is
[`../MASTER_VIDEO_PRODUCTION_PROMPT.md`](../MASTER_VIDEO_PRODUCTION_PROMPT.md); the rules are in
[`AGENTS.md`](../../AGENTS.md).
